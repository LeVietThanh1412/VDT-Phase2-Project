## Saved lightweight data

Content/SeaNavigation/quangninh_sectors.json contains 625 logical sectors, 25 columns by 25 rows, each 100 m. It is staged with the navigation chart. No 625-actor TargetPoint grid is created. IDs S00_00 through S24_24 use north-to-south rows and west-to-east columns. A middle column can straddle the team divider and is labeled Center; actual team-specific candidate positions must be checked against their side.

Each row records center and accepted anchor EN, longitude/latitude, normalized UV, team region, coastline water-area fraction, conservative chart sample fraction, shoreline clearance, nominal Small/Medium/Large suitability, connected-region ID, nearby island IDs, tactical zones, spawn/patrol prefilter flags and accepted candidate samples. Nine samples per cell refine coastline-boundary eligibility.

337 sectors have accepted chart samples. The principal field-connected group contains 332 sectors; two smaller groups contain four and one. Spawn/patrol flags exclude those disconnected groups. There are 295 spatial spawn candidates with at least 200 m anchor shoreline clearance. These are spatial candidates, not certified physical spawns. Nominal hull clearance is 65 m for Small and 112 m for the current Medium/Large geometry; runtime spawning must inspect the selected actual body bounds.

The source chart hash is saved in the data. The native loader checks it and rejects stale sectors. The original geographic A* implementation and chart remain unchanged.

## Generation and runtime API

Run from the project root:

```powershell
uv run --with shapely --with numpy --with pyproj --with pillow python Tools/NavalCombat/build_sector_battlefield.py
```

The builder accepts --sector-size for finer logical sampling; default is 100 m. Runtime data has a bounded 4 MiB loader budget. The chosen field location, width and yaw are explicitly validated against candidate 1. To change field geometry requires an intentional implementation change, rather than accidentally interpreting image pixels as world coordinates.

UNavalSectorSubsystem loads automatically in each Game/PIE world. Blueprint/Python can inspect Sectors, GridReady, GridError, dimensions and the frame. SectorAtChartPosition returns an array index or -1. FindSectorRoute returns existing native A* waypoints in EN meters and rejects routes outside the field or crossing excluded chart cells. ValidateRequiredConnections reports each required tactical connection. These queries do not command ships.
